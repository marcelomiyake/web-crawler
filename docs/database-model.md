# Web Crawler database model

This is the human-readable model of the crawler's PostgreSQL state and bounded archive. The migration is authoritative; update this inventory when it changes.

- **Owner:** `web-crawler`, shared `database/postgres/` schema.
- **Known consumers:** `web-crawler` / `crawler-api` owns job admission, query, and deletion; `web-crawler` / `crawler-worker` owns frontier execution, host leases, robots cache, and page outcomes. Both components share the same database. No cross-repository database consumer is identified.
- **Database:** PostgreSQL, default schema.
- **Source:** [`0001_initial.sql`](../database/postgres/migrations/0001_initial.sql).

## Tables

### `crawl_jobs`

| Column | Type and rules | Description |
| --- | --- | --- |
| `id` | UUID, primary key, generated by `gen_random_uuid()` | Crawl job identifier. |
| `idempotency_key` | TEXT, required, unique | Client key for idempotent job creation. |
| `request_fingerprint` | CHAR(64), required | Digest of the normalized request; detects conflicting key reuse. |
| `status` | TEXT, required; `running`, `completed`, or `completed_with_errors` | Overall job status. |
| `max_urls` | INTEGER, required, 1–500 | Hard maximum number of URLs for this job. |
| `max_depth` | INTEGER, required, 0–3 | Hard maximum link depth. |
| `created_at` | TIMESTAMPTZ, required, default `now()` | Job creation time. |
| `completed_at` | TIMESTAMPTZ, nullable | Job completion time. |

### `crawl_job_hosts`

| Column | Type and rules | Description |
| --- | --- | --- |
| `job_id` | UUID, required, FK to `crawl_jobs.id`, cascade delete | Job whose exact host allowlist contains this entry. |
| `hostname` | TEXT, required | Canonical hostname the job is allowed to fetch. |
| `(job_id, hostname)` | Composite primary key | One allowlist entry per hostname per job. |

### `host_state`

| Column | Type and rules | Description |
| --- | --- | --- |
| `hostname` | TEXT, primary key | Global coordination key shared across jobs and worker pods. |
| `lease_token` | UUID, nullable | Current worker's lease token. |
| `lease_expires_at` | TIMESTAMPTZ, nullable | Lease expiry time. |
| `next_request_at` | TIMESTAMPTZ, required, default `now()` | Earliest time any job may request this host again. |

### `frontier_urls`

| Column | Type and rules | Description |
| --- | --- | --- |
| `id` | UUID, primary key, generated by `gen_random_uuid()` | Frontier item identifier. |
| `job_id` | UUID, required, FK to `crawl_jobs.id`, cascade delete | Owning crawl job. |
| `canonical_url` | TEXT, required, at most 4,096 UTF-8 bytes | Normalized unique URL within the job. |
| `hostname` | TEXT, required | Host used for allowlist, robots, and shared spacing checks. |
| `depth` | INTEGER, required, 0–3 | Link depth from a submitted seed. |
| `state` | TEXT, required, default `queued`; `queued`, `leased`, `completed`, `skipped`, or `failed` | Frontier lifecycle state. |
| `attempts` | INTEGER, required, default `0`, 0–3 | Number of fetch attempts. |
| `next_attempt_at` | TIMESTAMPTZ, required, default `now()` | Earliest retry/claim time. |
| `lease_token` | UUID, nullable | Current worker claim token. |
| `lease_expires_at` | TIMESTAMPTZ, nullable | Claim lease expiry. |
| `last_error` | TEXT, nullable | Most recent fetch or policy error. |
| `http_status` | INTEGER, nullable | Response status when available. |
| `discovered_at` | TIMESTAMPTZ, required, default `now()` | Discovery time. |
| `completed_at` | TIMESTAMPTZ, nullable | Terminal processing time. |
| `(job_id, canonical_url)` | Unique constraint | Prevents duplicate URL work inside a job. |

### `robots_cache`

| Column | Type and rules | Description |
| --- | --- | --- |
| `origin` | TEXT, primary key | Origin whose robots policy was evaluated. |
| `outcome` | TEXT, required; `rules`, `allow`, `deny`, or `defer` | Cached robots resolution result. |
| `rules` | TEXT, required, default empty | Parsed or retained robots rule content when applicable. |
| `cached_at` | TIMESTAMPTZ, required, default `now()` | Cache creation time. |
| `expires_at` | TIMESTAMPTZ, required | Time after which the policy must be refreshed. |

### `page_snapshots`

| Column | Type and rules | Description |
| --- | --- | --- |
| `id` | UUID, primary key, generated by `gen_random_uuid()` | Archived page identifier. |
| `job_id` | UUID, required, FK to `crawl_jobs.id`, cascade delete | Owning job. |
| `frontier_url_id` | UUID, required, FK to `frontier_urls.id`, cascade delete | Successfully fetched frontier item. |
| `canonical_url` | TEXT, required | Normalized submitted/discovered URL. |
| `final_url` | TEXT, required | URL after allowed redirect handling. |
| `hostname` | TEXT, required | Resolved host recorded for the fetched page. |
| `title` | TEXT, required | Extracted HTML title. |
| `http_status` | INTEGER, required | Response status. |
| `depth` | INTEGER, required | Link depth at fetch time. |
| `content_type` | TEXT, required | Response content type. |
| `body` | BYTEA, required | Bounded retained response body. |
| `content_sha256` | CHAR(64), required | Digest of the stored body. |
| `fetched_at` | TIMESTAMPTZ, required, default `now()` | Fetch time. |
| `(job_id, frontier_url_id)` | Unique constraint | One stored page per frontier item in a job. |

### `archive_budget`

| Column | Type and rules | Description |
| --- | --- | --- |
| `singleton` | BOOLEAN, primary key, default `TRUE`, must remain `TRUE` | Enforces one global quota row. |
| `max_body_bytes` | BIGINT, required, greater than zero | Maximum accounted body bytes. |
| `used_body_bytes` | BIGINT, required, default `0`, non-negative | Currently reserved/retained body bytes. |
| `updated_at` | TIMESTAMPTZ, required, default `now()` | Most recent quota change. |

The migration creates the singleton quota row with a 6 GiB body budget. The quota tracks retained decompressed response bodies, not total PostgreSQL volume consumption. Job deletion cascades through job-owned host, frontier, and snapshot rows; global `host_state` and `robots_cache` entries are not job-owned.
